# 5. Базовые знания Linux

Для работы с программным комплексом мне важно понимать Linux на уровне диагностики и эксплуатации.

## Базовые понятия

Linux состоит из ядра и пользовательского окружения. Приложения работают как процессы, а фоновые компоненты часто запускаются как сервисы.

## Что нужно понимать

- процесс — выполняющаяся программа;
- сервис — управляемый фоновый компонент;
- файл и каталог — основные объекты файловой системы;
- права доступа определяют, кто может читать, изменять или выполнять объект;
- сеть связывает компоненты между собой.

## Практическое применение

При проблеме я могу определить, запущен ли нужный процесс или сервис, посмотреть его состояние, проверить файлы конфигурации и логи, а также проверить доступность сетевого взаимодействия.

Мне не требуется помнить каждую команду наизусть: важно понимать, какую информацию нужно получить и каким инструментом Linux её получить.

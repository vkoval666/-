# Безопасность учебного репозитория

Исходный релиз содержит файлы окружения и SSH-ключи, поэтому секреты нельзя публиковать в открытом GitHub-репозитории.

При переносе материалов в этот учебный репозиторий используются только безопасные исходники и документация. Файлы `.env`, private keys и реальные credentials не добавляются.

Это также часть практического понимания Git: перед публикацией нужно проверить, какие данные попадают в commit.

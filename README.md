# Подготовка к оценке: Software & Development

Этот репозиторий — моя рабочая шпаргалка для оценки знаний по разработке ПО.

Цель — понимать не команды сами по себе, а уметь объяснить, **что это такое, зачем применяется и как я могу применять это в своей разработке**.

## Главный принцип

Не просто знать определение термина, а уметь ответить на три вопроса:

- что это;
- зачем это нужно;
- как это можно применить в реальной разработке.

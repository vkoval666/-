# Исходный релиз

Исходный архив `erp-release-6009` был использован для анализа структуры и подготовки материалов. В нём около 2140 файлов, включая ComplexOS, UI, ERP frontend, mobile API, драйверы, сервисы, systemd units и вспомогательные инструменты.

Поскольку архив содержит environment-файлы и SSH-ключи, полный необработанный архив намеренно не публикуется в public repository.

Вместо этого в репозитории находятся:

- описание реальной архитектуры;
- карта систем и сервисов;
- безопасные примеры исходного кода;
- конкретные связи с MVP/MVI/Clean Architecture/DI/Resources;
- Linux и диагностика логов;
- вопросы и ответы для оценки.
